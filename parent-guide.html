The plain-language manual

Gurukool Parent Guide

Everything you need to run the site for your child — no technical terms, no jargon, and nothing that can break if you skip a section.

1 · The one-minute version

Gurukool is a small offline website with four training games — Math-Champ, Science-Champ, Mind-Champ and Samskritam-Champ — plus a central parent console. Your child opens the hub (index.html) or taps the home-screen icon on the iPad; everything else follows from there. Progress saves itself on the device instantly, and (if you set it up) silently to your private GitHub every 3 minutes.

2 · First-time setup (5 minutes)

On the iPad: open the site in Safari → the hub asks for your child's name and a parent PIN → then tap Share → Add to Home Screen. From the home-screen icon the app runs full screen with the ॐ icon.

The PIN: one 4-6 digit PIN protects both champs, the Admin Console and the Passport. If you forget it, the console's PIN reset clears it (progress is untouched).

On a second device: open the Admin Console → Cloud sync → connect the same GitHub repo. Progress flows both ways. Or skip the cloud entirely and use save codes from the Passport.

3 · What your child sees

Math-Champ: a home page that greets him by name, shows his rank and XP, and links to the Training Mission (the adaptive engine — it climbs when he's cruising, re-teaches when he wobbles), word problems, speed drills and the toolbox. The number pad appears under answer boxes on the iPad.

Science-Champ: the full game — 29 worlds of lessons, quiz ladders, the Chaos Arena, Professor Chaos missions, practice challenges, glossary and doubt jar.

XP and ranks are shared vocabulary: Rookie → Explorer → Challenger → Bronze/Silver/Gold Olympian → Gurukool Champion (2000 XP) in both champs. The hub scoreboard and the Passport show both champs side by side.

4 · Moving and backing up progress

The Passport (amber button on the hub) shows both champs and gives one combined code (GK1.) that moves everything. Importing is PIN-gated and merges — nothing is destroyed.

Cloud sync lives in the Admin Console only. Connect your private repo, and it auto-saves every 10 minutes with dated backups. The champs themselves carry no cloud/settings UI — nothing for your child to tap by accident.

5 · Troubleshooting

Progress looks wrong on the iPad? Fully close the app (app switcher) and reopen — Safari caches the old page.

New icon not showing? Remove and re-add the home-screen icon — the iPad takes its snapshot when you add it.

Forgot the PIN? Admin Console → the PIN reset flow (asks to confirm) → set a new one.

Never clear the website's data (Safari settings) — that is where progress lives on the device.
