👋 What is this website?

A personal training universe for your child, built to work completely offline — no accounts, no server, nothing tracked. It has two games today:

🧮 Math-Champ13 olympiad-style word problems taught step by step (Understand → Plan → Solve), timed calculation drills, a cheat-sheet toolbox and a progress dashboard.
🔬 Science-Champ29 science worlds (Physics Lab to ISRO missions) with 132 animated diagrams, a villain story mode (Professor Chaos), 1-hour mission sessions, quizzes and an arena.
🧩 LR-ChampComing later — logic puzzles.

All progress (XP, badges, streaks, journals) is saved inside the browser of the device being used.

🔒 Your ONE parent PIN

There is a single 4–6 digit PIN that protects both champs on this device. It is asked before anything that could change or erase progress:

  • Maths: Reset all progress, loading a progress code or file
  • Science: the Doubt Jar's parent view, resetting progress (Science Dashboard)
  • Admin Console: cloud sync settings, disconnecting sync, loading a backup file

Your child can freely play and learn — saving is fully automatic, and the PIN only guards the adult controls. The PIN lives on this device (it is not synced, not emailed, not stored anywhere else).

⚙️ Open the Admin Console
Forgot the PIN? The honest escape hatch: clear this website's data in the browser settings (Safari → Settings → this site → Clear data). That erases the PIN — and the local progress with it — so restore afterwards from the cloud (tap ☁️) or from your newest backup file. Keep a backup file somewhere safe and this is never more than a five-minute fix.

🧠 How your child trains

Maths — every word problem is solved in three guided stages: he first types what the problem tells him, then writes the equation, then solves it. His work is shown side-by-side with the expert's method, there are 3 hints per problem, and a timer with an "Olympian target" to beat. Speed Lab has 10-question timed drills.

Science — he picks a world, reads short story-driven lessons (with Sanskrit twin-words like vega वेग for speed), then proves it in the quiz ladder: Level 1 Foundation, Level 2 Olympiad Challenge (needs a perfect score), Level 3 Chaos Arena. The 1-hour Mission button mixes a recap, a story episode and a boss battle automatically.

The house rules (already built in): in Maths, problems unlock one by one — no skipping ahead, and Level 2 opens only after all of Level 1 is solved. The "next problem" button works only after solving the current one. He can always revisit solved problems to beat his time.

☁️ Cloud sync — one tap saves both champs

Set up once per device · a parent's 5-minute job

This stores your child's maths and science progress in a private file in your own GitHub account — your family's locker. After setup, saving is automatic: every Gurukool page silently syncs to the locker every 10 minutes while it is open, and the merge never destroys anything — best scores and badges are kept from every device. A dated backup file for your records downloads whenever you press Sync now in the Admin Console.

One name everywhere: the very first time the site opens, the Gurukool home page asks who is training today. That single name is used by Math-Champ and Science-Champ alike — he is never asked again (change it any time with the small ✏️ change name link on the home page). On a brand-new device the question appears once more, that is all.

  1. On github.com, create a new repository: any name (for example champs-progress), and choose Private. You don't need to add anything to it.
  2. Still on GitHub: click your profile picture → Settings → Developer settings (bottom of the left menu) → Personal access tokens → Fine-grained tokens → Generate new token.
  3. Name it anything (e.g. champ-sync). Under Repository access choose Only select repositories and pick the repo you just made. Under Permissions → Repository permissions → Contents, choose Read and write. For Expiration, choose No expiration — then it never runs out.
  4. Generate, then copy the token (it starts with github_pat_). GitHub shows it only once — paste it temporarily in your notes or email it to yourself.
  5. Open the Admin Console: Gurukool home page → bottom link ⚙️ Admin console → enter the parent PIN → fill your GitHub username, repo name and token → Save settings & sync now. That ONE setup powers every champ on the device — Math-Champ, Science-Champ and future ones like LR-Champ. From then on everything syncs by itself every 10 minutes; press Sync now in the console any time for an instant push plus a dated backup file.
Day-to-day: no routine needed — progress saves on the device instantly and to the family locker automatically every 10 minutes while any champ is open. On a new device: do the console setup once (same steps 2–5 — the same token works everywhere), and the latest progress arrives automatically when a champ page is opened (or press Sync now in the console).

If a token ever stops working (expired or revoked): nothing is lost. Progress stays on each device and in the repo. Just make a new token and paste it into the Admin Console.

📁 No cloud? Use the email route

Works with zero setup, forever:

  1. Tap ☁️ Sync anywhere — along with syncing it downloads a file named gurukool-progress-DATE.txt that holds both champs.
  2. Email that file to yourself or to whoever holds the other device.
  3. On the other device: open the site → Science ☁️ → 📂 Load a backup file (or Maths Dashboard → Load backup file) → choose the attachment → enter the parent PIN.
  4. Both champs' progress merges onto that device. The date in the filename tells you which copy is newest.

The old copy-paste codes still work too: the Maths "progress passport" (codes starting OC1.) and Science "Save Codes" — both merge, both are safe.

🗓️ A gentle weekly routine (5 minutes, Sunday evening is perfect)

  • Science home → 🫙 Doubt Jar (behind the PIN): anything your child found confusing sits here. Pick one or two to chat about — that conversation is worth more than an hour of drills.
  • Maths Dashboard: glance at the speed curve, badges and journal. Celebrate something specific.
  • Tap ☁️ once. Done.

Small and steady beats long and rare: 20–30 minutes a day with the mission timer is the sweet spot.

🛠️ Troubleshooting

"GitHub says 404"The repo name or username is mistyped in ☁️ settings, or the token doesn't include that repo.
"GitHub says 401/403"The token is expired or missing the Contents: Read and write permission. Make a new one.
"Could not save"Usually no internet, or the token lost write access. Local progress is unaffected — nothing is at risk.
Wrong device has newer progressOpen any champ on that device once — its auto-sync pushes the progress up, and this device pulls it within 10 minutes. Merging always keeps the best of both.
Fresh device looks emptySet up cloud in the Admin Console on it once — everything arrives automatically when a champ is opened (or press Sync now).
